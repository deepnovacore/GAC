# GAC-Qwen3.5-4B 发布说明

2026 年 10 月版本基于 Qwen3.5-4B 的 GAC 后训练模型，增加数学与通用对话的监督精炼，并以 BF16 发布推理权重。

本次公开表格采用这份权重的完整评测：4,447 题、11 个任务切片、解码 seed 0/1/2，每题每个 seed 生成一次，报告三次均值。各项统一使用温度 0.6、top-p 0.95、8,192 新 token 上限；代码和逻辑同样遵循这个发布评测配置。精确正确数、未取整分数及 BBH 三切片非加权平均见 EVAL_RESULTS.json。

复测此表请使用公开的版本化 release profile，而非通用 evaluator 的代码、逻辑默认预算。精炼阶段为 64 条数学与 64 条通用回放数据，2 epoch、LR 2e-6、batch 32、无拼接；评测用于模型开发，解码 seed 不代表独立训练 seed。原论文实验与当前模型评测分别展示，旧权重和模型卡保留在 Hub 历史中。

MMLU-Pro 固定数据版本和 1,000 题 ID；GPQA 需取得数据访问许可或提供合法取得的完整 CSV，不随模型分发。公开内容不包含集群路径、访问凭据或原始评测题。
